# AI Reception Pro V18 — English Overview

AI Reception Pro is a digital reception and appointment management project with separate **Administrator** and **Client** experiences.

**Stack:** Angular 19, Ionic 8, Capacitor 7, TypeScript, Python, SQLite and Android.

**Administrator:** dashboard, scheduling, customer and service management, AI assistant and conversation history, audio/video calls, messaging, email and settings.

**Client:** appointment booking, appointment consultation, AI assistant (subject to configuration), and a dedicated Android interface.

This public repository is a **portfolio and commercial showcase**, not a source-code distribution. The complete code and the five approved professional PDF documents can form part of a separately agreed commercial delivery. Buyer-side deployment and security acceptance testing are not yet certified.
